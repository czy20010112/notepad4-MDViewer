Third-party rendering assets for the Markdown preview pane, served to the
WebView2 pane through the mdpreview.assets virtual host. All are optional:
when the folder is missing the preview falls back to plain rendering.

- katex/    KaTeX 0.16.11 (MIT)          https://katex.org
- highlight/highlight.min.js + github theme, highlight.js 11.9.0 (BSD-3-Clause) https://highlightjs.org
- mermaid/  mermaid.min.js 11.12.1 (MIT) https://mermaid.js.org

See the LICENSE file in each folder.
